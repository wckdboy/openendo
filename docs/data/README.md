# docs/data — the OpenEndo data layer

Canonical, machine-readable open datasets for endometriosis research.
FAIR-packaged (RO-Crate), identifier-stable (`IDENTIFIERS.md`), MIT-licensed.

> **Relation to the live site:** openendo.org is a Lovable app that fetches
> trials/papers LIVE from ClinicalTrials.gov + PubMed via server functions.
> These JSON files are the **canonical archival + curated layer** — the app
> does NOT consume them yet (open decision, see CHECKPOINT top-3 #2). Agents:
> treat this directory as the source of truth for data, and flag
> `needs-lovable-sync` on PRs that change what the site should show.

## File contract

### A. Registry snapshots — GENERATED, do not hand-edit

| File | Content | Source | Cadence |
|---|---|---|---|
| `trials_global_recruiting.json` | recruiting endo trials worldwide | ClinicalTrials.gov API v2 | weekly, Mon 08:00 |
| `trials_denmark.json` | all registered endo trials in DK | ClinicalTrials.gov API v2 | weekly, Mon 08:00 |
| `trials_recent.json` | new/updated trials, last 7 days | ClinicalTrials.gov API v2 | weekly, Mon 08:00 |
| `pubmed_recent.json` | new papers, last 7 days | PubMed E-utilities | weekly, Mon 08:00 |
| `pubmed_monthly.json` | papers per month, ~6 months | PubMed E-utilities | weekly, Mon 08:00 |
| `meta.json` | generation metadata + counts | derived | weekly, Mon 08:00 |

Regenerated by `scripts/update_data.py` (Jaeger's zone, cron Mon 08:00).
Silent-when-unchanged; commits+pushes only on real change. **Never edit by
hand** — changes are overwritten next run. Schema changes → update the script
AND this table AND llms.txt AND the RO-Crate manifest, in one PR.

### B. Curated research outputs — agent-maintained (claim in CHECKPOINT first)

| File | Content | Source | Owner zone |
|---|---|---|---|
| `targets.json` | 58 drug targets (35 novel), ChEMBL-verified | Deep Origin list + ChEMBL audit (M1) | Percival |
| `repurposing_candidates.json` | 9 approved-drug candidates | M3 ChEMBL screen | Percival |
| `funding.json` | funding opportunities + deadlines | curated watch | shared |
| `content.json` | editorial copy EN/DA | curated | shared |
| `ro-crate-metadata.jsonld` | FAIR manifest of all datasets | generated — currently manual | RO-Crate CI task (CHECKPOINT 🟡) |

### C. Specs (not data)

- `IDENTIFIERS.md` — identifier rules. **Read before touching any dataset.**
  Never invent identifiers; keep NCT/PMID/CHEMBL verbatim; every external
  reference carries id + resolvable URL.

## Rules for agents

1. Read `IDENTIFIERS.md` + this table before editing any dataset.
2. Never hand-edit Group A files. To change curated files (Group B): claim the
   task in CHECKPOINT.md first, keep schema shape, bump `updated`, log it.
3. Adding a dataset? Update: this table, `docs/llms.txt`, the RO-Crate
   manifest, and the change log — one PR.
4. Every external link in curated data must resolve (HTTP 200) — CI checks.
5. No PII. Ever. (CI scans.)
