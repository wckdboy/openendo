## Contents

- `<GENE>.fasta` — canonical isoform sequence (one per target)
- `manifest.json` — machine-readable index (gene → UniProt accession,
  length, provenance, file)
- Regenerated by `python3 scripts/prepare_fold_input.py`

## How to fold (AlphaFold Server)

AlphaFold Server (https://alphafoldserver.com) is free for academic use and
needs **no local GPU** (~1–5 min per prediction):

1. Open https://alphafoldserver.com → *Create prediction*
2. Paste the sequence from `<GENE>.fasta` (single chain, protein)
3. Run → download results: `*_model.cif` (structure) + `*_summary_confidences.json`
4. Save as `docs/research/structures/results/<GENE>_model.cif` +
  `docs/research/structures/results/<GENE>_confidences.json`

Bulk automation: once the ShadowPC (RTX A4500 20 GB) is live, use
ESMFold / ColabFold locally for batch folding.

## After folding

Run the analysis pipeline:

```bash
python3 scripts/analyze_structure.py docs/research/structures/results/*.cif
```

which extracts per-target confidence (pLDDT), residue counts and pocket
candidates into `docs/research/structures/results/summary.json`.

## Rules

- Folds are **hypotheses**, not structures. Confidence (pLDDT) travels with
  every artifact.
- Everything here is open data (MIT) — sequences are public knowledge;
  predictions are generated for open research.
